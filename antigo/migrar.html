⚜ Migração para a v2

Copia os dados do app atual para a pasta nova / do banco. Os anexos ficam separados, em //anexos (sem Storage, sem custo). Nada do app atual é alterado ou apagado.
Verificando login…

1Conferir conexão

Testa seu login, a leitura dos dados atuais e a escrita na pasta nova.

2Simular (não grava nada)

Lê os dados atuais, mostra quantos anexos existem e confere se a conversão não perde nenhuma informação.

3Migrar para o teste

Move os anexos para a área de anexos e grava os dados na pasta /. Pode repetir à vontade: cada vez, a cópia de teste é refeita a partir dos dados atuais.

4Conferir se ficou igual

Lê de volta a cópia de teste e compara com os dados atuais, campo por campo.

5Apagar a cópia de teste (opcional)

Apaga só a pasta / do banco (dados e anexos de teste). Útil para recomeçar do zero.
